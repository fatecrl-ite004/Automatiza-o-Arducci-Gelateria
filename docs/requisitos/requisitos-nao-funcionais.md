
# Requisitos Não Funcionais

## Sistema de Gestão Integrada de Gelaterias

Os requisitos não funcionais estabelecem as características de qualidade, segurança, desempenho, compatibilidade e manutenção necessárias ao funcionamento adequado do sistema.

### Quadro de Requisitos Não Funcionais

| ID | Requisito não funcional | Descrição |
|---|---|---|
| RNF01 | Usabilidade | O sistema deverá possuir uma interface intuitiva e apresentar informações de forma clara e organizada. |
| RNF02 | Responsividade | O sistema deverá adaptar-se a diferentes tamanhos de tela, incluindo computadores, tablets e smartphones. |
| RNF03 | Desempenho | O sistema deverá responder às solicitações dos usuários em tempo adequado. |
| RNF04 | Segurança e controle de acesso | O sistema deverá exigir autenticação e restringir as funcionalidades conforme as permissões de cada perfil. |
| RNF05 | Integridade e confiabilidade dos dados | O sistema deverá manter os dados consistentes e evitar perdas ou alterações indevidas das informações armazenadas. |
| RNF06 | Disponibilidade | O sistema deverá estar disponível para utilização conforme as condições de funcionamento do ambiente em que estiver hospedado. |
| RNF07 | Facilidade de manutenção | O sistema deverá possuir uma estrutura organizada que facilite correções e atualizações futuras. |
| RNF08 | Compatibilidade | O sistema deverá funcionar nos principais navegadores utilizados para acessar a aplicação web. |
